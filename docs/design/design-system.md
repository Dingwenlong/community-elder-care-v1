# 社区独居老人照料系统 v1 视觉设计基准

- 状态：已确认
- 确认日期：2026-08-24
- 社区 Web 概念：`docs/design/concepts/admin-dashboard-v1.png`
- 老人端概念：`docs/design/concepts/elder-home-v1.png`
- 家属端概念：`docs/design/concepts/family-home-v1.png`

三张概念图是界面实现和视觉验收的基准，不作为产品运行时图片。界面文字、表格、按钮、图标和交互必须用 Vue、Flutter、HTML/CSS 或矢量图标原生实现。

## 1. 视觉方向

- 气质：克制、可信、清楚，接近社区公共服务工具，不做医院风格或营销页面。
- 背景：主内容使用纯白 `#FFFFFF`，不改成米白或暖灰。
- 社区侧栏：深蓝 `#0B376B`，选中项使用操作蓝。
- 主要文字：深海军蓝 `#071B3A`；次要文字 `#667085`。
- 主要操作：蓝色 `#0B6EEA`；悬停 `#075CC7`；焦点环 `#8CC0FF`。
- 边框与分隔：`#D8DEE8`；浅背景状态区 `#F6F8FB`。
- 紧急红：`#D92D20`，只用于已确认紧急等级、错误和危险确认，不用于普通“我需要帮助”。
- 家属端辅助状态：青绿 `#0E9F8F`，只表示已确认或已完成。
- 禁止：渐变、玻璃拟态、发光、装饰性胶囊、嵌套卡片、Bento 网格和无业务含义的图表。

## 2. 字体和可点击尺寸

- 中文字体：`Noto Sans SC`, `Microsoft YaHei`, `PingFang SC`, sans-serif。
- 社区 Web 正文：16px / 1.6；表格文字 15～16px；页面标题 28～32px。
- 老人端正文：不小于 18sp；主操作文字 24～30sp；问候语可达 36～44sp。
- 家属端正文：16～18sp；一级标题 28～34sp。
- Web 可点击区域不小于 44px；老人端主操作不小于 56dp；其他移动端控件不小于 48dp。
- 文字不能只靠颜色表达状态；关键状态同时使用文字和一致的线性图标。

## 3. 间距和容器

- 基础间距：4、8、12、16、24、32、48。
- Web 使用固定侧栏、顶栏、开放式主内容、列表轨道和表格；只在需要分组时使用单层平面容器。
- 移动端使用纵向开放布局、细分隔线和少量平面信息组；不把每一行包成卡片。
- 圆角：普通输入和按钮 6～8px；老人端大操作 12px；不使用夸张大圆角。
- 阴影：默认无阴影；仅浮层可使用轻微阴影。

## 4. 社区 Web 实现清单

首屏允许出现的固定文字：

- `社区独居老人照料系统`
- `社区工作人员`
- `演示数据`
- `工作台`、`老人档案`、`照料事件`、`探访任务`、`服务工单`、`设备信号`、`报告与审计`、`系统设置`
- `独居老人总数`、`今日探访任务`、`待处理事件`、`设备在线率`、`今日服务工单`、`本月完成探访`
- `待处理事项`
- `照料事件（按等级与等待时长优先）`
- `等级`、`等待时长`、`老人`、`当前责任人`、`下一步动作`
- `查看照料事件`

组件族：固定侧栏、顶栏身份区、紧凑指标行、待处理列表、照料事件表格、等级图标、文字链接、主按钮。紧急红只出现在紧急行；普通和需确认行不使用红色背景。

## 5. 老人端实现清单

首屏允许出现的固定文字：

- `社区独居老人照料系统`
- `演示数据`
- `李秀兰，上午好`
- `今日提醒`
- `上午 9:00 服药提醒`
- `下午 3:00 社区探访`
- `我今天平安`
- `我需要帮助`
- `送达状态`
- `尚未送达` 或 `今天已签到`
- `首页`、`提醒`、`陪我聊聊`、`我的`

首屏只有两个大操作：蓝色实心的“我今天平安”和深蓝描边的“我需要帮助”。选择紧急类别并完成二次确认前，首页不显示红色。天气使用种子数据或本地缓存。

## 6. 家属端实现清单

首屏允许出现的固定文字：

- `家属照料进展`
- `李秀兰的家属账号`
- `演示数据`
- `仅显示老人已授权的摘要`
- `最近状态`
- `今天 08:42 已平安签到`
- `今日提醒 1/2 已完成`
- `社区最近确认 08:50`
- `照料进展`
- `社区正在电话确认`
- `已安排次日回访`
- `报告联系不上老人`
- `当前授权范围`
- `最近状态、事件摘要、探访摘要`
- `最近状态`、`事件`、`照料记录`、`我的`

家属端不出现精确地址、健康风险明细、原始 AI 对话、社区内部备注、责任队列或事件状态修改入口。“报告联系不上老人”使用蓝色描边，不暗示已完成真实联系。

## 7. 图标和交互

- 使用同一套 2px 左右描边的线性图标；选中导航可以实心蓝色呈现。
- 固定图标语义：主页、档案、事件铃、日历、工单、设备信号、审计盾牌、设置齿轮、签到盾牌、帮助救生圈、消息、用户。
- 不使用纯文字箭头替代导航图标；方向符号使用矢量图标。
- 所有按钮必须有默认、悬停/按下、焦点、禁用和提交中状态。
- 支持 `prefers-reduced-motion`；只使用短促状态过渡，不使用装饰动画。

## 8. 响应式边界

- 社区 Web 设计基准为 1600×1000 左右；在 1280px 宽度仍保留侧栏和完整事件表格。
- 低于 1024px 时允许折叠侧栏，但不能把表格改成装饰卡片网格。
- 老人端和家属端以 360～430dp 宽度为主；不得出现水平滚动、文字截断或依赖横向手势。

## 9. 最终视觉验收

实现后必须分别截取社区 Web、老人端和家属端主屏，与对应概念图并排检查：固定文字、信息层级、颜色、字号、间距、容器模型、图标风格、响应式和核心交互。任何偏差要么修复，要么在验收记录中说明为经确认的有意差异。
