## 主故事回读

浏览器自动化从重置开始，等待唯一漏签事件，再注入一条设备异常证据。事件经过受理、探访、模拟家属电话、模拟急救转运、解决、随访和结案。最终回读满足：

- 全程使用同一个事件编号。
- 受理、解决、结案各有一条状态记录。
- 探访完成证据只有一条。
- 家属电话和急救转运各有一条模拟联系记录。
- 家属撤权后下一次读取返回 `CONSENT_REQUIRED`。
- 跨片区读取被拒绝；紧急临时授权要求理由，最长 15 分钟并留下审计记录。

自动化彩排连同启动和停止耗时 57 秒，浏览器中的主故事本身耗时 35 秒。最近一次重置耗时 636 毫秒。系统保存了一份忽略于 Git 的 WebM 备用录像；人工讲解仍按 6 分钟讲稿执行。
