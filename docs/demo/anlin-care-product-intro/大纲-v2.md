- 产品名：安邻照料——社区独居老人照料协同系统
- 形式：网页 PPT + PDF 备份
- 页数：8 页，16:9

- 建议讲述时长：4.1 分钟，为 5 分钟介绍保留翻页和停顿时间

## 使用说明

- 方向键、PageUp/PageDown 翻页，Home/End 跳转首尾页。
- Esc 打开总览；P 进入演讲者模式；B 切换低功耗模式。
- 演讲者模式支持计时、排练、备注保存、观众屏同步、黑白屏、冻结、激光笔和圈选。
- 页面截图保留原始界面文字；移动端截图只按页面槽位裁取可见区域，不重绘内容。
